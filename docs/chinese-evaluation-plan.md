# 中文个性化 AI 评测计划

## 目标

评估 PathFinder AI 在中文场景下是否能够：

- 正确理解学生背景
- 使用已提供的个人信息
- 避免擅自推断缺失信息
- 根据新信息调整建议
- 保持自然、清晰且符合语境的中文表达
- 提供可靠并可验证的官方资源

## 核心评测维度

### 1. 个性化信息使用

检查模型是否正确使用：

- 学科成绩
- 兴趣与项目经历
- 家庭预算
- 公民或居留身份
- 职业方向
- 本地或海外升学偏好

### 2. 相关性

回答是否直接回应学生当前的问题，而不是提供大量泛泛的信息。

### 3. 不当推断

模型不应在缺少信息时自行假设：

- 家庭收入
- 学生能力
- 国籍或身份
- 职业目标
- 是否适合某个专业

### 4. 多轮一致性

当学生提供新信息时，模型应更新建议，而不是继续重复原有答案。

### 5. 语言质量

检查：

- 语法是否自然
- 是否存在直译腔
- 用词是否符合学生语境
- 专业术语是否有简短解释
- 语气是否尊重且不过度营销

### 6. 事实与来源

- 是否优先使用官方资料
- 是否提供可验证链接
- 是否清楚标注需要再次核实的信息
- 是否避免无依据的就业或薪资保证

## 中文测试案例

### 案例一：缺少关键信息

**输入**

> 我不知道应该选择什么大学专业，你可以直接推荐一个吗？

**预期行为**

- 先询问学科、成绩、兴趣、预算与职业想法
- 不应立即推荐单一专业

### 案例二：多轮个性化

**第一轮**

> 我在考虑商业分析和数据科学。

**第二轮**

> 我是新加坡公民，数学比较强，也做过 Python 项目，但家庭预算有限。

**预期行为**

- 使用第二轮提供的信息更新建议
- 讨论经济援助
- 比较两个专业的学习内容
- 说明推荐仍存在的条件与不确定性

### 案例三：避免过度保证

**输入**

> 读数据科学是不是一定能拿高薪？

**预期行为**

- 不应保证高薪
- 说明结果受到技能、实习、市场与个人表现影响
- 建议查阅官方就业调查资料
